## Resumen
Este repositorio contiene datos y recursos relacionados con **estadísticas mundiales de salud mental**. Es parte de una iniciativa de ciencia abierta para compartir hallazgos de investigación y conjuntos de datos con la comunidad científica global.

## Estructura del Repositorio
- `data/`: Contiene los conjuntos de datos utilizados en esta investigación.
- `src/`: Código fuente para el procesamiento y análisis de datos.
- `results/`: Archivos de salida, figuras y métricas.
